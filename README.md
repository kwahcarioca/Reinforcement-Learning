# Reinforcement Learning: From Theory to Practice

Welcome to my Reinforcement Learning (RL) study repository. This space brings together academic notes, practical implementations in Python, and technical articles covering key concepts in RL—from fundamental multi-armed bandit problems to advanced algorithms.

---

## 📂 Repository Structure

* **`K-bandidos/`**: Comprehensive study on the K-Armed Bandit problem.
  * **`notebooks/`**: Interactive Jupyter/Google Colab notebooks with simulations and comparative analysis of agents ($\epsilon$-greedy, UCB, Thompson Sampling, Gradient Bandit).
  * **`paper/`**: Technical article *"From Theory to Code: Implementing K-Armed Bandits with Design Patterns"* available in English and Spanish.

---

## 🛠️ Stack & Concepts
* **Language:** Python 3.x
* **Core Libraries:** Gym, NumPy, Matplotlib
* **Architectural Patterns:** Object-Oriented Programming (OOP) & Design Patterns
* **Key Literature:** Sutton & Barto (*Reinforcement Learning: An Introduction*), Lattimore & Szepesvári (*Bandit Algorithms*), Maxim Lapan (*Deep Reinforcement Learning Hands-On*)
